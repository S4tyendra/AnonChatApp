  Reconnection Flow:                                                        
  1. Client loses connection → server starts30s grace period                
  2. Peer notified with peer_disconnected: temporary                        
  3. If client reconnects within30s:                                        
  - Gets reconnected event                                                  
  - Gets connected event with same peer name                                
  - Peer gets peer_reconnected event                                        
  4. If grace period expires → full cleanup, peer put back in queue

  - Listen for retry: header - EventSource uses this automatically          
  - Handle reconnected event to know session was restored                   
  - Handle peer_disconnected to show "peer may be reconnecting..." UI       
  - Handle peer_reconnected when peer comes back

  - RECONNECT_GRACE_PERIOD_MS=30000 (default30s)
